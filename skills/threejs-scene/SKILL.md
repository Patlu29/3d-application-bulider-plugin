# Three.js scene conventions

## Canvas setup

Keep exactly one `<Canvas>`, in `src/scene/Experience.tsx`:

```tsx
import { Canvas } from "@react-three/fiber";
import { Suspense } from "react";

export function Experience() {
  return (
    <Canvas
      dpr={[1, 2]}
      camera={{ position: [3, 2, 5], fov: 45, near: 0.1, far: 100 }}
      gl={{ antialias: true, powerPreference: "high-performance" }}
    >
      <Suspense fallback={null}>
        <Lights />
        <Product />
      </Suspense>
    </Canvas>
  );
}
```

- Clamp `dpr` to `[1, 2]`; never use the raw device pixel ratio on high-density phones
- Enable `shadows` only when the design needs real-time shadows
- Use `frameloop="demand"` for scenes that are static until the user interacts, and call `invalidate()` after changes
- React Three Fiber already sets sRGB output and ACES Filmic tone mapping, so do not set them again

## Structure

- One component per scene object in `src/scene/objects/`
- Lights in `src/scene/lights/` and camera rigs in `src/scene/cameras/`
- Use materials and shaders from `src/scene/materials/` and `src/scene/shaders/`; do not define them inline
- Group related meshes with `<group>` and position the group, not each mesh

## Loading models

```tsx
import { useGLTF } from "@react-three/drei";

export function Product(props: JSX.IntrinsicElements["group"]) {
  const { scene } = useGLTF("/models/product.glb");
  return <primitive object={scene} {...props} />;
}

useGLTF.preload("/models/product.glb");
```

- Always load inside `<Suspense>`
- Preload models needed for the first view
- Use the typed components generated by the technical artist when they exist
- Clone the scene with `scene.clone()` if the same model appears more than once, or use instancing

## Lighting starter

- Image-based lighting first: drei `<Environment preset="studio" />` or an HDR from `public/env/`
- Add at most one shadow-casting directional light
- Use `ContactShadows` or baked shadows instead of real-time shadows where possible

## Animation

```tsx
import { useFrame } from "@react-three/fiber";
import { useRef } from "react";
import type { Mesh } from "three";

export function Spinner() {
  const ref = useRef<Mesh>(null);
  useFrame((_, delta) => {
    if (ref.current) ref.current.rotation.y += delta * 0.5;
  });
  return <mesh ref={ref}>{/* ... */}</mesh>;
}
```

- Always multiply motion by `delta` so speed does not depend on frame rate
- Never call `setState` inside `useFrame`; mutate refs instead
- Read store values in `useFrame` with `useStore.getState()`, not with the hook, to avoid re-renders
- Never allocate objects such as `new Vector3()` inside `useFrame`; create them once outside the loop

## Events

- Use React Three Fiber pointer events: `onClick`, `onPointerOver`, `onPointerOut`
- Call `event.stopPropagation()` so only the nearest object responds
- Set the cursor on hover with `document.body.style.cursor` and reset it on pointer out

## Talking to the UI

- Read and write shared state only through the stores in `src/state/`
- Never import from `src/ui/`

## Disposal

- React Three Fiber disposes of objects it creates declaratively when they unmount
- Dispose of anything you create manually (geometries, materials, textures, render targets) in a cleanup function
